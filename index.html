L’objectiu d’aquesta pràctica és explorar tres tipus de visualitzacions de dades: l’histograma, un isotype chart i un beeswarm chart.

Per tal de posar en pràctica cada una de les visualitzacions utilitzarem l’eina RStudio per tal de realitzar cadascuna de les representacions.

El conjunt de dades escollit per aquest anàlisi s’ha obtingut de Kaggle, anomenat Students Performance in Exams que compta amb 1000 dades i les següents 8 variables:

  1. gender: gènere de cada alumne (female,male);
  2. race.ethnicity: ètnia de cada alumne amb classificació segons grup (A, B, C, D, E);
  3. parental.level.of.education: nivell d’educació dels pares (bachelor’s degree, some college, master’s degree, associate’s degree, high school, some high school);
  4. lunch: classificats segons standard o free/reduced;
  5. test.preparation.course: si els alumnes han realitzat alguna preparació prèvia als examens (none, completed);
  6. math.score: nota de cada alumne a l’examen de matemàtiques;
  7. reading.score: nota de cada alumne a l’examen de lectura;
  8. writing.score: nota de cada alumne a l’examen de redacció.

És una base de dades que conté les classificacions obtingudes pels estudiants en diverses assignatures per tal de comprendre la influencia dels antecedents familiars, la preparació dels examens o el rendiment dels estudiants entre altres.

Histograma

El histograma és una tècnica de visualització que permet analitzar la distribució de dades numèriques contínues. Va ser popularitzat per l’estadístic Karl Pearson a finals del segle XIX, tot i que el concepte de representar freqüències amb barres ja existia anteriorment. Funciona agrupant les dades en intervals (anomenats bins) i mostrant la freqüència de cada interval amb barres verticals, on l’alçada reflecteix el nombre de casos dins de cada rang. És ideal per identificar patrons com la simetria, la dispersió o la presència de valors atípics en variables com edats, temperatures o ingressos.

Les dades adequades són quantitatives i contínues (per exemple, mesures o valors que poden prendre decimals), i es recomana un mínim de 30 observacions per evitar interpretacions enganyoses.

Una limitació important és que l’elecció de l’amplada dels intervals pot alterar la percepció de la distribució: intervals massa estrets generen soroll, mentre que els massa amples amaguen detalls.

Per a les nostres dades, podem crear un histograma amb ggplot segons les notes dels alumnes a l’examen de matemàtiques, per tal de veure la tendència general respecte la nota mitjana de tots ells, ja que ens agrupa les notes en intervals i mostra quantes persones cauen en cada rang, permetent-nos identificar on es concentren la majoria de les notes, la simetria o presència de possibles grups diferenciats. Afagirem també la mitjana de les notes totals, representada en vermell.

# Carregar les llibreries necessàries
library(ggplot2)

# A continuació, es crea el histograma utilitzant ggplot2

# Calcular la mitjana de les puntuacions de matemàtiques
mitjana_math <- mean(StudentsPerformance$math.score)

# Crear histograma de math.score amb bins més petits i una línia vertical per la mitjana
ggplot(StudentsPerformance, aes(x = math.score)) +
  geom_histogram(binwidth = 2, fill = "blue", color = "black", alpha = 0.7) +  # Ajustem el binwidth
  labs(
    title = "Distribució de les puntuacions de matemàtiques",
    x = "Puntuació de Matemàtiques",
    y = "Nombre d'alumnes"
  ) +
  scale_x_continuous(breaks = seq(0, 100, by = 5)) +  # Afegim etiquetes més detallades a l'eix X
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1)) +  # Inclinem les etiquetes de l'eix X per millorar la llegibilitat
  geom_vline(aes(xintercept = mitjana_math), color = "red", linetype = "dashed", size = 1) +  # Afegim la línia vertical per la mitjana
  annotate("text", x = mitjana_math + 2, y = 75, label = paste("Mitjana =", round(mitjana_math, 2)), color = "red", size = 4)  # Afegim el text de la mitjana

Beeswarm Chart

El beeswarm chart (o diagrama d’eixam) és una tècnica que visualitza dades individuals sense superposar-los, creant un efecte similar a un eixam d’abelles. Deriva de gràfics de punts tradicionals (com el scatter plot), però optimitza l’espai mitjançant algorismes que distribueixen els punts de manera uniforme al llarg d’un eix. Va guanyar rellevància en àmbits com la biologia o les ciències socials per analitzar distribucions en mostres mitjanes (entre 100 i 500 punts).

És ideal per a dades quantitatives agrupades en categories (com comparar l’alçada de persones per país o notes d’exàmens per assignatura), ja que mostra tant la densitat com els valors individuals.

Les seves principals limitacions són la dificultat per gestionar conjunts massius (>1000 punts) i la necessitat d’eines específiques per generar l’efecte d’eixam. A diferència de l’histograma, preserva la precisió de cada dada, cosa que el fa útil per a anàlisis detallades però requereix més atenció per part de l’usuari.

En el nostre cas podem fer un gràfic amb el paquet ggbeeswarm que té R, per classificar la les notes de cada alumne segons el grup ètnic dels alumnes i el seu gènere.

# Instal·lar i carregar el paquet ggbeeswarm (si no el tens instal·lat)

library(ggbeeswarm)

# Crear beeswarm chart separant per ètnia i amb el gènere com a color
ggplot(StudentsPerformance, aes(x = race.ethnicity, y = math.score, color = gender)) +

Isotype chart

El gràfic Isotype és una tècnica dissenyada per comunicar dades de manera visualment intuïtiva mitjançant icones o símbols. Va ser creat pel filòsof Otto Neurath als anys 1920 com a part del moviment Isotype (International System of Typographic Picture Education), amb l’objectiu de democratitzar l’accés a la informació. Cada icona representa una quantitat concreta (per exemple, una casa = 1000 habitatges), permetent comparacions ràpides entre categories.

És útil per a dades qualitatives o quantitatives discretes (com el nombre d’escoles per regió o espècies animals en un ecosistema), sempre que es puguin associar a símbols reconeixibles

Les dades han de ser senceres i eviten decimals per garantir claredat. Tot i la seva accessibilitat, aquesta tècnica no és adequada per a valors molt grans o variables complexes, ja que l’excessiva repetició d’icones pot dificultar la lectura.

Amb el nostre dataset podem fer una classificació segons les notes i el tipus de dinar que han consumit els alumnes. Per exemple, podem caregoritzar segons la mitjana de les notes de cada alumne entre alta (qualificacions de 80 a 100), mitjana (60 a 80) i baixa (menors a 60). Podem veure quants alumnes de cada categoria han sonsumit un tipus de dinar o altre i veure si el tipus d’alimentació influeix en el rendiment total en els examens. Per a un dinar estàndard ho representarem amb pomes vermelles i el menjar gratuït/reduït serà representat amb pomes grises. El gràfic final obté per cada franja 10 pomes, que representen la quanttat d’alumnes que han ingerit un tipus de menjar o altre segons el rendiment. Per les icones utilitzarem la llibreria emojifont.

library(tidyr)
library(emojifont)

load.emojifont()

#Configurar dades i ordenar franges
StudentsPerformance <- StudentsPerformance %>%
  mutate(
    average_score = (math.score + reading.score + writing.score) / 3,
    performance = case_when(
      average_score >= 80 ~ "Alta [80-100)",
      average_score >= 60 & average_score < 80 ~ "Mitjana [60-80)",  # Afegir el límit superior a 80
      TRUE ~ "Baixa (<60)"
    ) %>% factor(levels = c("Alta [80-100)", "Mitjana [60-80)", "Baixa (<60)"))
  )

#Preparar dades amb posicions ordenades
df_plot <- StudentsPerformance %>%
  group_by(performance) %>%
  summarise(
    standard_prop = sum(lunch == "standard") / n(),
    free_prop = 1 - standard_prop
  ) %>%
  mutate(
    standard_pomes = round(standard_prop * 10),
    free_pomes = 10 - standard_pomes
  ) %>%
  pivot_longer(
    cols = c(standard_pomes, free_pomes),
    names_to = "tipus",
    values_to = "n_pomes"
  ) %>%
  mutate(
    color = ifelse(tipus == "standard_pomes", "#FF0000", "#808080"),
    emoji = "🍎"
  ) %>%
  uncount(n_pomes) %>%
  group_by(performance) %>%
  mutate(posicio = row_number()) 

# Crear el gràfic
ggplot(df_plot, aes(x = posicio, y = performance, color = color)) +
  geom_text(
    aes(label = emoji),
    family = "EmojiOne",
    size = 12,
    position = position_nudge(x=-0.2, y = 0.1)
  ) +
  scale_color_manual(
    values = c("#FF0000" = "#FF0000", "#808080" = "#808080"),
    breaks = c("#FF0000", "#808080"),
    labels = c(" Menjar estàndard", " Menjar gratuït/reduït"),
    guide = guide_legend(
      title = NULL, 
      override.aes = list(
        label = "🍎",     # Afegeix l'emoji
        size = 6          # Ajusta la mida de la poma a la llegenda
      )
    )
  ) +
  labs(
    title = "Notes obtingudes segons el tipus de menjar",
    subtitle = "Cada poma representa un 10% dels estudiants en la franja de notes",
    x = NULL,
    y = NULL
  ) +
  theme_minimal() +
  theme(
    axis.text.x = element_blank(),
    axis.text.y = element_text(size = 14, face = "bold", color = "black"),  # Mostra franges
    panel.grid = element_blank(),
    plot.title = element_text(hjust = 0.5, face = "bold", size = 16),       # Títol centrat i negreta
    plot.subtitle = element_text(hjust = 0.5, size = 12),
    plot.margin = margin(2, 1, 4, 1, "cm")  # Espai per la llegenda
  )

En el gràfic podem veure que 5 de cada 10 persones que han obtingut baixa qualificació han menjat menjar estàndard. En les qualificacions mitjanes, ha estat 7 de cada 10 alumnes i, finalment, 8 de cada 10 estudiants que han obtingut qualificacions altes han consumit menjar estàndard. Cosa que es pot concloure que tenir una bona alimentació durant els exàmens influeix significativament en les notes finals i, per tant, en el rendiment dels alumnes.
